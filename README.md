# AI Debate Arena

Three AI agents debate any topic live — one argues for, one against, one judges and scores.

## Run it
Open the artifact directly in Claude.ai, or use the standalone HTML version with a Groq API key (free at console.groq.com).

## Stack
- React (single artifact)
- Claude Sonnet 4 via Anthropic API (streaming)
- Judge returns structured JSON scores
- All state in React useState
